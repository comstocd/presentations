## Slide Format

All presentations (31–41) are full-screen HTML slide decks using a consistent format:

- Light theme, white background, dark slate text — projection-ready
- iPad-optimized with swipe navigation; keyboard arrow support on desktop
- Progress bar and slide counter
- Scrollable slide bodies for dense content
- No external dependencies, no build step — single `.html` file per deck
- No emojis; talking-point format throughout

Each deck includes: title slide with case vignette or framing, pathophysiology, clinical reasoning framework, comparison tables, drug cards or treatment matrices, clinical pearls, and a references slide citing primary guidelines and landmark trials.

## Evidence Standards

All topic decks are built from **MKSAP 19** (ACP, October 2025) as the primary source, supplemented by:

- IDSA, ATS, ACC/AHA, GOLD guidelines
- Landmark RCTs (DOSE, EMPULSE, OVIVA, POET, EAST-AFNET 4, INTERACT2, ADVOR, RACE II, CABANA)
- Open Evidence comparison passes verifying accuracy and completeness against current literature (2023–2026)

Deep-dives with factual corrections have been completed for decks 31, 33, 34, 35, 36, 37, 38, 39, 40, and 41.
